# orig/

Put your own copy of the game here. Nothing in this directory except this
file and the `.sha1` list is tracked.

The target is 東方花映塚 1.50a (2005-10-07), the last update: the files
from the retail CD (1.00, 2005-08-14, the `kaei/` directory on it),
updated by the official `th09_ver150a.lzh` patch from
<https://www16.big.or.jp/~zun/data/soft/th09_ver150a.lzh>. Extract
`th09_ver150a.exe` from it, put it in the game directory and run it.

```
orig/th09_150a/            the installed game
orig/th09_150a/th09.exe    updated to 1.50a
```

```sh
sha1sum -c th09_150a.sha1
```

`th09.dat` must be the original, patched to 1.50a; English patches
replace it.
